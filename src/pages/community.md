## Start with a contribution

- **Improve the specification.** Report an ambiguity, discuss a requirement, or
  propose an interoperable extension in the
  [specification repository](https://github.com/agentnameservice/ans-registry/issues).
- **Build and test.** Choose an [implementation or SDK](../ecosystem/), try it in
  your environment, and report reproducible issues in its repository.
- **Improve the documentation.** Clarify an example, correct a link, or explain a
  working integration and its assumptions.
- **Review and help.** Review a proposed change, reproduce an issue, or answer a
  question. These contributions are part of maintaining the project.

Read the target repository's contribution guide before submitting a pull request.
The [ANS contribution guide](https://github.com/agentnameservice/ans-registry/blob/main/CONTRIBUTING.md)
covers the specification workflow. Sign off your commits under the Developer
Certificate of Origin and follow the project's
[Code of Conduct](https://github.com/agentnameservice/ans-registry/blob/main/CODE_OF_CONDUCT.md).

## Where discussion happens

Use GitHub issues and pull requests in the relevant repository for technical
questions and proposed changes. Include your environment, the behavior you expected,
and enough detail for someone else to reproduce the issue.

## Share an integration

Open an issue with public source, installation instructions, the ANS features it
supports, and tests showing that invalid identities or requests are rejected.
Document limitations and distinguish examples and research previews from supported
releases. A working integration should explain where verification is enforced and
what changes when it fails.

## Report sensitive issues through the right channel

Follow the affected repository's security policy for suspected vulnerabilities.
Start with the [specification security policy](https://github.com/agentnameservice/ans-registry/blob/main/SECURITY.md)
or find the affected project in the [implementation directory](../ecosystem/).
Use the reporting process in the Code of Conduct for conduct concerns.
